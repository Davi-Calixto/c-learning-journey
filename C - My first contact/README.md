# My First Contact with C

These five exercises represent my **first contact with the C programming language**.

At this stage, the goal was not to write complex or optimized programs, but to understand the basic structure of C and start developing problem-solving skills through simple exercises.

## What I Practiced

Throughout these exercises, I worked with some of the fundamental concepts of C:

* Variables and data types
* `scanf()` and `printf()`
* Arithmetic operations
* `if / else` statements
* Comparison operators
* The modulo operator `%`
* Basic program structure
* Reading and processing user input

## Exercises

The five exercises cover different basic problems, such as:

1. Reading three integer values.
2. Comparing two values and performing different operations depending on whether they are equal.
3. Checking whether a number is even or odd.
4. Adding different values depending on the number's parity.
5. Performing basic mathematical calculations with user input.

## Purpose

These exercises are the beginning of my journey with C.

They may be simple, but they represent the point where I started learning how programs are structured, how data is processed, and how logical decisions are implemented in code.

More advanced concepts will be added as I continue studying the language.
